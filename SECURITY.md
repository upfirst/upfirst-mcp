# Security policy

## Report a security problem

Please do not open a public issue for a security problem.

Email [support@upfirst.ai](mailto:support@upfirst.ai) and put "Security" in the subject. Tell us:

- what you found,
- how to reproduce it,
- what it affects.

We will reply as soon as we can.

## Scope

- The hosted Upfirst MCP server at `https://mcp.upfirst.ai` and the Upfirst sign-in it uses.
- The files in this repository.

Read more about how we protect your data on our [Security](https://upfirst.ai/security) page.
